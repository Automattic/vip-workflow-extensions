# TypeSafe Connector

Registers [TypeSafe](https://docs.typesafe.ai/introduction) in **Settings → Connectors** so the API key lives in the same place, and behaves the same way, as the keys for WordPress's AI providers.

## Why a connector and not a settings page

TypeSafe returns typed judgments (a choice, a probability, a score), not generated text, so WordPress does not treat it as an AI provider and does not register it. Without this plugin every plugin that calls TypeSafe would need its own field for the key. With it there is one place to enter the key, one place to revoke it, and the same precedence Core uses for its own connectors.

## Requirements

- WordPress 7.0 or later (the Connectors API). On older versions the plugin does nothing.
- A TypeSafe API key from the [TypeSafe console](https://console.typesafe.ai/settings/keys).

This plugin does **not** require VIP Workflows, and it does not depend on any other plugin in this repository. It is the one extension here without a `Requires Plugins: vip-workflows` header, on purpose: it is a Core registration that any plugin can build on.

## Configuring the key

The key is resolved in this order, first match wins:

1. The `TYPESAFE_API_KEY` environment variable.
2. A `TYPESAFE_API_KEY` constant, for example in `wp-config.php`.
3. The value saved in Settings → Connectors.

On VIP, prefer the environment variable or the constant so the key never sits in the database. Nothing in this repository stores or ships a key.

## Reading the key from another plugin

Ask Core rather than hardcoding an option name:

```php
$connector = wp_get_connector( 'typesafe' );
$auth      = $connector['authentication'] ?? array();
// $auth['setting_name'] is the option name Core generated. Apply the precedence above.
```

The `workflow-typesafe-categorize` extension in this repository does exactly this.

## What it registers

| Field | Value |
| --- | --- |
| Connector id | `typesafe` |
| Type | `service` |
| Authentication | `api_key` |
| Constant and environment variable | `TYPESAFE_API_KEY` |
| Setting name | generated by Core, `connectors_service_typesafe_api_key` |

Unsupported example code, like everything in this repository. See the root README.
